# v1.4 可信数据与自动复算设计

## 目标

一份标准家庭状态同时服务上下文保存、确定性计算和工作流。每个关键步骤的完整性由控制器基于实际步骤输出复算；外部提交的PASS只能补充证据，不能决定结果。

## 数据结构

新增family-state.schema.json，固定币种、金额单位、收入/支出周期、税收口径、支出是否含债务还款、资产分层、债务余额和字段来源。计算就绪要求税后年收入、全年总支出、可动用资产组成和债务列表口径明确。未知值使用null或待确认状态，不使用0。

input.schema.json成为工作流输入封装；family-context.schema.json包含标准family_state及目标、未决问题和决策记录。旧0.9上下文由迁移脚本转换；无法安全映射的合并金融资产进入unallocated_financial_assets并标记NEEDS_CONFIRMATION，不进入正式计算。

## 自动复算

完整性引擎从实际步骤输出复算：

- baseline：净资产、结余；
- housing：每个方案的置换价差和买后流动资产；
- financing：每笔按揭月供或续贷缺口；
- education：费用情景单调性；
- career：收入转型恒等式；
- stress：每个方案每个情景的期末现金、最低现金、储备触线和现金缺口；
- options：方案ID与住房、融资、压力测试覆盖一致。

控制器将自动复算结果与外部证据合并，实际复算FAIL直接隔离，缺少可复算字段返回WARN。STRESS_TEST和OPTIONS_VALIDATE纳入关键完整性门禁。
