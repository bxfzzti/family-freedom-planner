# 个性化首次问诊示例

## 1. 换房 + 职业

用户：
> 我38岁，两个孩子，想换房，但是担心40岁以后工作不稳。

生成：
```text
我先按你刚才说的帮你填好一部分：

我 38 岁；
我们有 2 个孩子；
未来几年想换房；
同时担心 40 岁后收入稳定性。

你只补这些：

伴侣年龄【 】岁；
家庭税后年收入大约【 】万；
家庭一年大约花【 】万；
现金+金融资产大约【 】万；

当前房大约值【 】万，还欠【 】万；
目标房大约【 】万；

当前主要高收入还能稳定【 】年 / 到【 】年。

你最想判断的是：
【买房后还能不能降低工作强度 / 其他】
```

## 2. 一方脱产

用户：
> 老婆明年可能辞职在家带娃。

生成不应包含换房问题，除非对话中已有住房压力。

## 3. 首次购房

用户：
> 我们没房，手里120万，想知道可以买多贵。

生成不应询问“当前房值多少”。
