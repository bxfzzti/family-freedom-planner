# 职业转型与收入降档

## 高收入不是永续资产

必须识别：

> 当前主要高收入还能相对安全持续多久？

把它作为 Deadline。

## 三阶段模型

### 当前高收入期
目标：提高储蓄、降低未来单点依赖。

### 过渡期
不把“离开高薪岗位”和“停止工作”当成同一天。

可能收入：

- 副业；
- 顾问；
- 远程工作；
- 低强度岗位；
- 项目收入。

### 长期低强度状态
用户真正希望长期维持的家庭收入和生活方式。

## 副业验证

重点不是单月峰值，而是：

- 过去12个月净收入；
- 是否重复；
- 是否依赖单一客户；
- 离开主业后能否继续；
- 是否覆盖强制现金流的一部分。

## 职业自由线

不是简单“25倍支出”。

定义：

> 当前最高收入岗位失效时，家庭可以用低强度收入 + 可动用金融资产 + 可压缩支出运行，而无需卖核心住房、也无需在3—6个月内找到同等高薪。

通常需要：

- 住房和教育关键问题基本落位；
- 约2年应急资金；
- 买房后仍有流动资产；
- 副业/低强度收入被验证；
- 重大贷款没有无法处理的本金；
- 计划不依赖房价上涨或高投资收益。
