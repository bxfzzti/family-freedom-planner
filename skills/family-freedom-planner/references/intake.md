# 首次问诊：模块化低摩擦输入

首次使用时，不要假设每个家庭都同时有房子、孩子、贷款、职业转型。

默认使用：

> **基础主干 + 可选模块**

以下内容是 Agent 的内部字段池。按 intent-to-intake.md 自动选相关内容，每轮最多问三个独立信息项；用户主动要表格时才提供对应片段。

不知道的地方直接写“不知道”。

---

# 可选模块

## B. 有房 / 换房 / 卖房 / 租房

适合：

- 已有住房；
- 想换房；
- 想卖房租住；
- 想买学区房；
- 想改善住房。

```text
【住房模块】

我们现在有【 】套房。

主要住房大约值【 】万，
还欠贷款【 】万，
贷款利率约【 】%，
每月实际还款大约【 】元。

这套房未来我倾向：
【继续住 / 一定会卖 / 可能卖 / 不知道】

如果换房，我大概想买【 】万左右的房子，
主要为了：
【学区 / 面积改善 / 通勤 / 父母同住 / 其他】

如果先卖后租，
我能接受的月租大约【 】元，
最多接受租【 】年。

我最担心的是：
【房价继续跌 / 目标房涨 / 卖不掉 / 买贵了 / 租房体验 / 其他】
```

# 推荐用户组合

为了进一步降低选择成本，可以直接告诉用户：

### 如果你主要纠结换房
复制：
**A 基础 + B 住房**

### 如果你纠结孩子上学和换房
复制：
**A 基础 + B 住房 + D 教育**

### 如果你纠结 40 岁后离开高薪工作
复制：
**A 基础 + E 职业**

### 如果你纠结买房后还能不能离职
复制：
**A 基础 + B 住房 + E 职业**

### 如果伴侣准备全职带娃
复制：
**A 基础 + F 脱产**

如果还涉及房贷：
再加 **G 负债与融资**

### 如果想回县城 / 小城市
复制：
**A 基础 + E 职业 + I 迁移**

### 如果家里问题特别复杂
复制：
**A 基础 + 与自己最相关的 3 个模块**

不建议第一次选择超过 3 个可选模块。

# Agent 发送规则

首次问诊时，不要把 A—J 所有模块一次性全部发给用户。

先根据用户已经说出的关键词，自动推荐 2—4 个最相关模块。

例如用户说：

> “我想换学区房，但是担心40岁工作不稳定。”

Agent 应发送：

- A 基础主干；
- B 住房；
- D 教育；
- E 职业。

不要发送父母、迁移、投资模块。

如果用户完全没有透露方向，则先展示：

1. A 基础主干；
2. “你还可以选：住房 / 教育 / 职业 / 脱产 / 贷款 / 父母 / 迁移 / 投资”。

---

# 首轮响应原则

用户提交后：

1. 先给一句话诊断；
2. 算 3—5 个关键数字；
3. 找 2—3 个 Deadline；
4. 给第一版判断；
5. 只有一个缺失变量真的会改变结论时，再问一个。

不要因为用户没有选某个模块就默认他“没有”这个问题。

未提及 = `UNKNOWN`，不是 `NO`。
