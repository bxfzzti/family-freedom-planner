# 核心家庭模型

## 基本计算

`家庭稳定收入 = 两位成人稳定税后收入 + 可验证副业 + 其他稳定收入`

`年度结余 = 家庭稳定收入 - 家庭真实年支出`

`储蓄率 = 年度结余 / 家庭稳定收入`

`家庭净资产 = 总资产 - 总负债`

必须拆分：

- 现金；
- 低风险资产；
- 股票/基金等高波动金融资产；
- 自住房；
- 其他房地产；
- 其他不可快速变现资产；
- 债务。

## 可迁移资产

即离开当前公司、城市或职业后仍能使用的资产。

通常包括：

- 现金；
- 可投资金融资产；
- 用户愿意出售的资产；
- 已验证、可持续的副业/咨询能力。

通常不包括：

- 用户明确不卖的终局自住房；
- 当前职位本身；
- 尚未实现的房价上涨；
- 尚未验证的未来工资。

## 强制现金流

3—6个月内难以削减的支出：

- 基础生活；
- 房租/房贷；
- 基础教育；
- 必要医疗保险；
- 赡养；
- 必须支付的债务。

## Runway

`Runway（月） = 可动用低风险资产 / 月度强制现金流`

至少看：

- 当前；
- 一方脱产；
- 高收入失效。

## 高收入依赖度

`高收入依赖度 = 可能失效的单一高收入 / 家庭稳定收入`

用于提醒单点依赖，不用于评价个人。

## 房产锁定率

`房产锁定率 = 用户不计划出售的房地产净值 / 家庭净资产`

高房产锁定率不代表贫穷，但代表职业、教育和应急可用资产可能不足。

## Deadline Collision

如果：

- 24个月内 ≥2 个重大不可逆事件；或
- 36个月内 ≥3 个重大事件，

标记 `deadline_collision = true`。

默认响应：

1. 保留更多流动性；
2. 避免多个不可逆动作同年发生；
3. 提前解决确定性最高的Deadline；
4. 推迟纯改善型支出。
